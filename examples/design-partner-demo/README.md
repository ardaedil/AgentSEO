# AgentSEO Design-Partner Example

This folder contains the customer-facing artifacts used in the 10-minute Phase 2A demonstration.

- `breaking-pr-report.md`: accepted real-agent example where protocol/schema compatibility passes and behavioral compatibility fails.
- `safe-pr-report.md`: accepted real-agent example for the safer description-only change.
- `sample-agentic-contract.yaml`: one model-independent behavior and safety contract.
- `sample-github-action.yml`: a minimal pull-request workflow using provider credentials from GitHub Actions secrets.

Follow [`docs/DESIGN_PARTNER_DEMO.md`](../../docs/DESIGN_PARTNER_DEMO.md) for the timed narrative and
exact commands. Replaying these reports makes no API calls. The reports are small real-provider
observations intended to demonstrate the product workflow, not to rank models or estimate general
reliability.
